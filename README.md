# Programação Web — Fatec Registro

Academic record of web-programming exercises developed during the Multiplatform Software Development program at Fatec Registro. The repository includes a personal timeline page and separate hands-on exercises in HTML, CSS, and basic JavaScript.

## Learning topics

| Directory | Topic |
| --- | --- |
| `aula-01-hello-word/` | First HTML page |
| `aula-02-semantica/` | Semantic HTML |
| `aula-03-git-e-github/` | Git/GitHub practice |
| `aula-04-midias-e-formatações/` | Text and media elements |
| `aula-05-midias-gerais-exercicio/` | Media exercise |
| `aula-06-tabelas/` | HTML tables |
| `aula-07-estilizacao-basica/` | CSS fundamentals |
| `aula-08-pseudo-classes/` | CSS pseudo-classes |
| `aula-09-pseudo-elementos/` | CSS pseudo-elements |
| `aula-10-posicionamento-layout/` | Box model, positioning, display, and Flexbox |

## Running the exercises

No package manager or backend is required. Clone the repository and open `index.html` in a browser. For individual lessons, open the corresponding HTML file. A local static server is recommended if browser restrictions affect assets or navigation.

```bash
git clone https://github.com/vftheodoro/PW-FATEC.git
cd PW-FATEC
```

## Repository notes

- `index.html`, `style.css`, and `script.js`: academic timeline/homepage.
- Each `aula-*` folder contains independent coursework files.
- Some timeline entries describe future semesters and are placeholders, not completed academic work.
- The third lesson currently contains `teste.html`; a link in the homepage references `aula-03-git-e-github/index.html`. This mismatch needs a separate source-code fix.
